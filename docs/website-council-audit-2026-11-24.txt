FEATURE INVENTORY

1. Accounts: email/password login and registration, password reset/recovery,
   sign-out, guest practice, account-specific local progress, remote profile sync.
2. Home: suggested starting practice, resume paused sessions, next drill,
   progress/XP/rank summary, favorite drill shortcut and account prompt.
   Some richer metrics described in older documentation now live elsewhere.
3. Solo practice: Fallacy Hunter, Rebuttal Practice, Quick Drills and Steelman
   Challenge; difficulty choice, shuffled questions/options, answer explanations,
   points, streak/combo feedback, summaries, recommendations and pause/resume.
   Local preview showed banks of 9, 7, 9 and 7 questions respectively (32 total).
4. Daily/Arcade: rotating four-question daily challenge, daily completion and
   bonus XP, countdown, goals/quests, combos and unlockable achievements.
5. Profile: display name, avatar/private storage, XP/rank, streak, drill records,
   mastery estimates and live debate record. Core progress sync is best-effort;
   it is incorrect to describe all app progress as local-only.
6. Leaderboards: personal device XP plus explicitly labelled sample standings;
   live ELO standings query Supabase. A genuine live XP ranking is not implemented.
7. AI debate: custom/suggested/current topics, publisher links, random topic/side,
   stance and opponent difficulty, 3/5 turns, written or recorded speech,
   written timing options, AI replies/referee, turn feedback, coaching,
   labelled local fallback and optional Devil's Advocate follow-up drill.
8. Speech: microphone recording, cancellation/cleanup, transcription,
   editable transcript review, private audio upload and playback.
9. Multiplayer: public matchmaking and queue cancellation, private invite rooms,
   written/speech turns, server-time clocks, thinking/turn statistics, transcript,
   AI referee, live ELO, completion/winner rewards, match rating and rematches.
10. Study: six lessons across argument, source evaluation, reasoning and response
    paths; recall, worked examples, practice, reflection, spaced review,
    weekly goals, Field Notes, return-visit reminders and classroom handoff.
    Lateral reading already has a lesson; it should be extended, not reintroduced.
11. Paper Study: signed-in PDF text extraction; question/method/finding/limitation
    summaries and flashcards; exact passage/page citations and PDF preview.
    Limits: selectable-text PDF, 10 MB, 40 pages and 100,000 extracted characters.
    Scanned PDFs need another solution. Materials are browser-tab scoped.
12. Classroom: organizations/cohorts, invitations/codes and roles; position-paper,
    drill and AI/live/private debate assignments; templates/duplication,
    draft/published states, deadlines, attempt/late/file/reply policies,
    configurable rubrics, submissions, grading/feedback, private attachments,
    announcements/read receipts, discussions/moderation, archive/delete and analytics.
13. Evidence Lab: motion or specific-claim research; Exa/OpenAlex searches and
    bounded recovery searches; subquestions, supporting/challenging/context sources,
    excerpt/abstract provenance, exact-quote and scope checks, record deduplication,
    uncertainty/abstention, investigation trace, source links and saved quote cards.
14. Evidence practice: use a cited quote in an argument, answer an AI challenge,
    revise, inspect original/revised wording and citation feedback; return/resume
    between the evidence investigation and practice round.
15. Platform: responsive shell, mobile navigation, light/dark theme, skip link,
    focus management, reduced-motion styling, offline banner, PWA manifest/service
    worker, health endpoint, authenticated function proxy, request IDs/timeouts.
16. Club preview: separate browser-only sample workflow in public/demo/. Treat
    it as a demonstration rather than a persisted classroom/club product.

PRIORITIES
P0 = needed before broad/public use; P1 = next product work; P2 = later opportunity.
Observed = source or local UI establishes the behavior. Verify = a test or wider
review is needed. Proposal = an enhancement, not a confirmed missing capability.
Items involving privacy/age controls are product recommendations, not legal advice.

CORRECTNESS AND RELIABILITY

01 [P0, Observed] Consolidate duplicate live clock effects. App.tsx:417 and :510
   install equivalent intervals that both invoke timeout submission. Deduplicate
   the client calls and test server idempotency; an actual duplicate turn was not observed.
02 [P0, Observed] Correct classroom completion denominators. Classroom.tsx:422-430
   divides each student's work by all published assignments when All classrooms is
   selected. Use only assignments in that student's eligible cohorts.
03 [P0, Observed] Normalize cross-assignment score analytics. Classroom.tsx:433
   averages raw scores despite configurable maxima. Show comparable percentages
   or separate scales; a 5/5 and a 5/20 must not be treated as equivalent performance.
04 [P1, Observed] Show students criterion-level rubric feedback. Scores are stored
   per criterion, but the student feedback view shows total/comment. Display the
   rubric before submission and earned/possible points after publication.
05 [P0, Verify] Complete real-account release checks for invitation email,
   teacher/student permissions, attachments, retry-safe submissions, two-player
   debates, speech and AI/evidence providers. README expressly leaves these open.
06 [P0, Observed/Verify] Add live-room reload/reconnect recovery. App.tsx initializes
   Home, remaps room history to lobby, and reads then subscribes without explicit
   reconnect reconciliation. Resume authorized rooms and resnapshot after subscription.
07 [P1, Observed] Renew signed recording URLs. App.tsx:430 caches five-minute URLs
   without expiry refresh. Renew on play/expiry and test replay after a long match.
08 [P1, Observed] Define the Daily Challenge timezone and persist the run's date.
   UTC date keys and a local-midnight countdown can disagree. Define late finishes
   and test a paused run across midnight, travel and daylight-saving changes.
09 [P1, Observed] Preserve Quick Drill remaining time. The effect restarts at five
   seconds after resume and interval ticks can drift. Use a deadline or preserve
   remaining time, with explicit timed versus accommodation rules.
10 [P0, Observed] Fix the offline navigation fallback: sw.js caches each successful
   navigation under the same './' key. Visiting /demo/ can replace the app fallback.
   Cache documents by route and test app -> demo -> offline app.
11 [P0, Observed] Scope and version caches. The service worker has a static cache
   name and a broad same-origin GET strategy. Allowlist public assets, exclude
   API/auth responses, bound storage, and verify updates. No data leak was demonstrated.
12 [P0, Verify] Make CI checks discoverable and mandatory: typecheck, build,
   existing evidence tests, critical browser journeys and backend contract checks.
   React package scripts currently expose only dev/build/start; tests do exist.

COUNCIL SYNTHESIS
Strongest recurring themes: verify existing end-to-end behavior; validate assessment;
preserve learners' work; connect existing tools into one learning journey.
Some models favored live XP rankings/tournaments. Those are deferred until reward
integrity, privacy and actual demand are established. Argument maps are promising
but less urgent than recovery and feedback correctness. Code/guest checks cannot
prove all authenticated or multi-user workflows; a test passing is not a provider benchmark.
